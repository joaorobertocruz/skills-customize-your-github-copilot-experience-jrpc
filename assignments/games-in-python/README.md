
# 📘 Atividade: Hangman Game

## 🎯 Objetivo

Construir um jogo da Forca em Python para praticar manipulação de strings, loops, condicionais, entrada de dados e seleção aleatória.

## 📝 Tarefas

### 🛠️ Build the Hangman Game

#### Descrição

Crie um jogo no qual o jogador deve adivinhar as letras de uma palavra oculta antes de esgotar o número permitido de tentativas.

#### Requisitos

O programa concluído deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Aceitar palpites de letras informados pelo jogador.
- Exibir o progresso da palavra oculta, por exemplo, `_ _ _ _`.
- Rastrear e exibir o número de tentativas incorretas restantes.
- Encerrar quando o jogador adivinhar a palavra ou esgotar as tentativas.
- Exibir uma mensagem clara de vitória ou derrota.
